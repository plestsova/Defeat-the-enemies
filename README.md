# 🏹 Space Shooter

Простая аркадная игра-стрелялка на HTML5 Canvas. Уничтожай скелетов стрелами, проходи волны и набирай очки!

![Скриншот игры](rot.png)

---

## 🎮 Как играть

| Клавиша | Действие |
|---------|----------|
| **← → ↑ ↓** | Движение персонажа |
| **Пробел** | Выстрел стрелой вправо |
| **Клик мышью / любая клавиша** | Включить музыку (если браузер её заблокировал) |

---

## 🎯 Цель игры

- Уничтожь **всех скелетов** на уровне, пока не вышло время
- Всего **5 волн**, каждая сложнее предыдущей
- Время на волну уменьшается: **10 → 8 → 6 → 4 → 2 секунды**
- За каждого убитого скелета — **+10 очков**
- Победи все 5 волн и получи надпись **«ТЫ ВЫИГРАЛ!»**
- Не успел убить всех — **«ТЫ ПРОИГРАЛ!»**

## 🚀 Как запустить локально

### Вариант 1: Просто открыть в браузере

1. Скачай все файлы в одну папку
2. Открой **`index.html`** двойным кликом
3. Играй! 🎮

### Вариант 2: Через локальный сервер (если музыка не играет)

**Python:**
```bash
python -m http.server 8000
```

**Node.js:**
```bash
npx serve
```

Открой в браузере: **http://localhost:8000**

## 🌐 Как задеплоить (разместить в интернете)

### GitHub Pages (бесплатно)

1. Создай репозиторий на [github.com](https://github.com)
2. Загрузи все файлы через **Add file → Upload files**
3. Перейди в **Settings → Pages**
4. Source: **Deploy from a branch** → **main** → **/ (root)** → **Save**
5. Через 1–2 минуты игра будет доступна по адресу:
   ```
   https://твой_ник.github.io/имя_репозитория/
   ```

### Netlify Drop (30 секунд)

1. Открой [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащи папку с игрой мышкой
3. Получи готовую ссылку!

## ⚙️ Настройки (внутри `index.html`)

В начале скрипта можно легко подкрутить игру:

```javascript
const FPS = 60;                  // Частота кадров
const PLAYER_SPEED = 7;          // Скорость персонажа
const BULLET_SPEED = 15;         // Скорость стрелы
const ENEMY_SPEED = 5;           // Начальная скорость скелетов
const MAX_WAVES = 5;             // Количество волн
const WAVE_BASE_TIME = 10;       // Время первой волны (сек)
const WAVE_TIME_STEP = 2;        // Насколько меньше каждая следующая
const POINTS_PER_KILL = 10;      // Очков за убийство
```

## 🐛 Известные особенности

- **Музыка не стартует автоматически** — это ограничение браузеров. Нажми любую клавишу или кликни мышью, чтобы её включить.
- **Через `file://`** (двойным кликом) некоторые браузеры могут блокировать звук. Используй локальный сервер или хостинг.
